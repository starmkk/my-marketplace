# 모델 프로필 전환

전역 CLAUDE.md `Model by difficulty` 의 모델별 배정만 세션 단위로 교체함. 그 외 규칙(위임 기준,
번들링, `model` 명시, 조용히 통과하는 실수 = 핵심 로직, effort, 보고 형식)은 그대로 적용.

## 인자

| 인자 | 동작 |
|---|---|
| `opus` 또는 없음 | 이 세션 끝까지 아래 opus 위주 배정 적용 |
| `fable` | 전역 CLAUDE.md 기본 배정으로 복귀 |

## opus 위주 배정

| 모델 | 담당 |
|---|---|
| `haiku` | 기계적 치환, 파일 목록, 형식 변환 |
| `sonnet` | 포팅, 비핵심 구현(배선·CLI I/O·빌드 파일·JNI/Java 보일러플레이트), 테스트, 주변 스크립트(빌드·데이터 준비), 문서 초안, 소스 대조, 수치 재계산 |
| `opus` | 계획·설계 결정, **핵심 로직 구현**(모듈 중심 알고리즘·공개 API + 그 TDD 테스트), 원인 분석, 상충 근거 판정, 반박 검토 |
| `fable` | opus 결과가 불신·상충이거나 오판 비용이 매우 클 때의 에스컬레이션 전용 |

- 핵심 로직의 반박 검토는 구현 에이전트와 다른 새 opus 에이전트가 수행

## 적용 절차

1. 사용자에게 한 줄로 확인: 적용된 프로필, 그리고 메인 세션 모델이 opus 가 아니면 `/model opus`
   전환 안내(스킬은 메인 세션 모델을 바꾸지 못함)
2. 이후 Agent 호출·workflow 단계의 `model` 값을 위 표로 결정
3. 이 표를 서브에이전트 프롬프트에 넣지 않음 — 배정은 `model` 값으로만 전달
