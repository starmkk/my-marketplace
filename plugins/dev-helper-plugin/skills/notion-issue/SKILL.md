# Notion 이슈 등록·갱신

등록은 **사용자가 요청할 때만** 한다. 리포트 조치 항목·작업 중 발견한 문제를 스스로 이슈화하지
않는다(필요해 보이면 등록할지 묻는다).

## 대상

| 항목 | 값 |
|---|---|
| 이슈 DB | `collection://41be93ff-c5a8-815a-8719-000bed58e099` (루트 페이지 「Claude Code 리포트」) |
| 리포트 DB(관련 리포트 연결 대상) | `collection://41be93ff-c5a8-818a-9215-000b32131bbe` |
| 속성 | `제목` · `상태`(백로그·보류·진행중·완료) · `우선순위`(높음·보통·낮음) · `영역`(다중) · `호스트`(공통·aip1·aip2) · `관련 리포트`(relation) · `기한`(date) · `생성일`(자동) |

- 스키마가 바뀌었을 수 있으면 먼저 `notion-fetch` 로 이슈 DB 를 읽고 실제 속성 이름을 따른다
- Notion 도구가 없으면(커넥터 미연결) 등록하지 않고 그 사실과 이슈 초안을 보여 준다

## 등록 절차

1. **내용 정리** — 요청과 지금 대화에 있는 근거만으로 아래를 채운다. 새 조사는 하지 않는다
   - `제목`: 문제를 한 줄로(해결책이 아니라 증상·목표). 예 "github-commit 실행 시 토큰 과다 소비"
   - `우선순위`: 요청에 있으면 그대로, 없으면 영향 범위로 판단(작업 차단·데이터 손실 위험 → 높음)
   - `영역`: 기존 옵션(토큰 비용·plugin·리포트 파이프라인·환경 설정)에서 고르고, 특정 프로젝트면
     프로젝트명(예 `SoundAI.Lite`)을 옵션으로 추가
   - `호스트`: 특정 호스트 문제면 그 라벨(`hostname` 소문자 — voiceguard 는 호스트 네트워크라 호스트와
     같음), 아니면 `공통`
   - `기한`: 요청에 날짜가 있을 때만(상대 날짜는 KST 기준 절대 날짜로)
   - `관련 리포트`: 요청이 특정 날짜·리포트를 가리키면 리포트 DB 에서 `키` 또는 `기간` 으로 찾아 연결
2. **중복 확인** — 이슈 DB 에서 완료가 아닌 이슈 중 제목 핵심어가 겹치는 것을 조회. 같은 문제로
   보이면 새로 만들지 말고 기존 이슈에 내용을 덧붙일지 묻는다
3. **등록** — `notion-create-pages`(parent `data_source_id`), `상태` 는 `백로그`(요청에 "진행"이
   있으면 `진행중`). 본문 템플릿:

   ```markdown
   ## 배경
   - 요청 요지와 계기(날짜 포함)

   ## 원인·근거
   - 확인된 사실과 수치(출처: 파일 경로·커밋·측정 명령). 추정은 "추정" 표시

   ## 요청 내용
   - 사용자가 원하는 결과

   ## 완료 조건
   - [ ] 확인 가능한 조건(수치·명령·화면). 요청에 없으면 "(초안)" 을 붙여 제안

   ## 참고
   - 관련 파일·커밋·문서 링크
   ```

4. **보고** — 이슈 링크, 제목, 상태·우선순위·영역 한 줄. 초안으로 채운 항목이 있으면 그 항목을 알린다

## 상태·결과 갱신

이슈를 맡아 작업을 시작·종료할 때, 또는 사용자가 상태 변경을 요청할 때 갱신한다.

- 착수 → `진행중`, 중단·대기 → `보류`(사유를 본문 `## 진행 기록` 에 한 줄), 완료 조건 충족 → `완료`
- `notion-update-page` 로 `상태` 를 바꾸고, 본문 끝 `## 진행 기록` 에 `YYYY-MM-DD — 무엇을 했는지 ·
  결과(커밋·수치·경로)` 한 줄을 `insert_content` 로 추가. 완료 조건 체크박스는 충족한 것만 체크
- 완료 처리는 완료 조건이 실제로 확인됐을 때만. 확인하지 못한 조건이 남으면 `진행중` 으로 두고 남은
  조건을 보고

## 목록

- "열린 이슈"·"이슈 목록" → 이슈 DB 에서 `상태` ≠ 완료 를 우선순위·생성일 순으로 조회해 표로 보여 준다
  (제목 · 상태 · 우선순위 · 영역 · 기한)

## 하지 않는 것

- 요청 없이 이슈 생성, 사용자가 등록한 이슈의 제목·완료 조건 임의 변경
- 비밀 값(토큰·키·비밀번호)을 본문에 옮기기 — 위치만 적는다
